# 📖 Il Mio Ricettario

Un'applicazione web dedicata alla gestione e consultazione di ricette culinarie, pensata per organizzare i tuoi piatti preferiti in modo semplice ed intuitivo.

---

## 🚀 Caratteristiche Principali

- 🥗 **Gestione Ricette:** Visualizzazione, inserimento e organizzazione delle ricette.
- 🔍 **Ricerca e Filtri:** Trova facilmente le ricette in base agli ingredienti o alle categorie.
- 📱 **Interfaccia Responsive:** Design ottimizzato per la consultazione sia da PC che da smartphone (comodo in cucina!).
- ⏱️ **Dettagli Preparazione:** Tempi di cottura, porzioni ed elenchi ingredienti chiari.

---

## 🛠️ Tecnologie Utilizzate

### **Frontend**

- **Framework / Libreria:** HTML5, CSS3, JavaScript _(oppure React / Vite)_
- **Styling:** CSS Personalizzato / Responsivo

### **Backend / Database** _(Modifica/aggiungi se presenti)_

- **Tecnologie:** Node.js / Express _(o JSON Locale / LocalStorage)_
